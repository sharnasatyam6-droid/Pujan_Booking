# वैदिक पूजन-पाठ

यह वेबसाइट श्री सत्यनारायण पूजन हेतु निवेदन स्वीकार करने के लिए बनाई जा रही है। आगन्तुकों के लिए पूरी सामग्री हिन्दी और संस्कृत में रखी गई है।

## परियोजना

- `index.html` — मुख्य पृष्ठ और पूजन निवेदन-पत्र।
- `css/style.css` — मुख्य पृष्ठ की रूप-सज्जा।
- `js/main.js` — मुख्य पृष्ठ के व्यवहार और निवेदन एपीआई से जुड़ाव।
- `admin.html` — निजी व्यवस्थापक पटल; प्रकाशित वेबसाइट पर `/admin` से खोलें।
- `css/admin.css`, `js/admin.js` — व्यवस्थापक पटल की रूप-सज्जा और व्यवहार।
- `api/` — सर्वर पर चलने वाले एपीआई मार्ग।
- `lib/server.js` — साझा सुरक्षा, सत्र, आँकड़ा-भण्डार और ईमेल सहायक।
- `database/schema.sql` — PostgreSQL तालिकाएँ और प्रारम्भिक पूजन सेवा।
- `backend/README.md` — आँकड़ा-भण्डार और वर्सेल स्थापना के पूरे निर्देश।
- `vercel.json` — वर्सेल प्रकाशन विन्यास।

## प्रकाशित करने से पहले

1. Neon में PostgreSQL आँकड़ा-भण्डार बनाएँ और `database/schema.sql` चलाएँ।
2. वर्सेल में `DATABASE_URL`, `ADMIN_USERNAME`, कम-से-कम १६ अक्षरों का `ADMIN_PASSWORD` और कम-से-कम ३२ अक्षरों का `SESSION_SECRET` जोड़ें।
3. GitHub से वर्सेल पर प्रकाशित करें।
4. `/api/health` और `/admin` जाँचें तथा एक परीक्षण निवेदन भेजें।

विस्तृत चरण [पृष्ठभाग निर्देश](backend/README.md) में हैं।

**महत्त्वपूर्ण:** कोड तैयार है, पर जब तक वास्तविक आँकड़ा-भण्डार और वर्सेल पर्यावरण मान विन्यस्त नहीं होते, तब तक वास्तविक निवेदन स्वीकार नहीं हो सकेंगे। अभी ऑनलाइन भुगतान नहीं है। पूजन की तिथि व्यवस्थापक द्वारा ग्राहक से पुष्टि किए जाने तक निश्चित नहीं मानी जाएगी।
