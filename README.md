# श्री सनातन पूजन सेवा

आचार्य कमलेश महाराज के लिए हिन्दी-प्रधान पूजन बुकिंग एवं पूजन-सामग्री वेबसाइट। ग्राहक पूजन का निवेदन भेज सकते हैं और सामग्री अलग से मँगाने का विकल्प भी है।

## स्थापित करना
1. इस रिपॉज़िटरी को Vercel में आयात करें; Framework Preset को Other रहने दें।
2. Neon में PostgreSQL डेटाबेस बनाएँ और database/schema.sql को Neon SQL Editor में एक बार चलाएँ।
3. Vercel Project Settings → Environment Variables में DATABASE_URL जोड़ें। Neon का pooled connection string उपयोग करें।
4. Deploy करें और /api/health खोलकर जाँचें।

## उपलब्ध API
- GET /api/health — डेटाबेस स्थिति
- GET /api/pujans — सक्रिय पूजन सूची
- GET /api/products — सक्रिय सामग्री सूची
- POST /api/bookings — पूजन निवेदन
- POST /api/orders — सामग्री का अलग आदेश निवेदन

## अभी बाकी उत्पादन कार्य
व्यवस्थापक का सुरक्षित प्रवेश और प्रबंधन पटल, वास्तविक Razorpay order creation/signature verification/webhook, तिथि-समय टकराव रोकना, सामग्री का भुगतान/वितरण प्रवाह और उत्पादन सुरक्षा परीक्षण आवश्यक हैं। अभी वेबसाइट कोई भुगतान सफल होने का दावा नहीं करती। अग्रिम राशि प्रति पूजन निश्चित है; निवेदन भेजना बुकिंग पुष्टि नहीं है। पूरे भारत में सेवा यात्रा एवं तिथि की उपलब्धता के अधीन है।
