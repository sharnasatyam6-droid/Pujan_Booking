# श्री सनातन पूजन सेवा

आचार्य कमलेश महाराज के लिए हिन्दी-प्रधान पूजन बुकिंग एवं पूजन-सामग्री वेबसाइट। ग्राहक पूजन का निवेदन भेज सकते हैं और सामग्री अलग से मँगाने का विकल्प भी है।

## Vercel और Neon पर स्थापित करना
1. इस रिपॉज़िटरी को Vercel में आयात करें; Framework Preset को Other रहने दें।
2. Neon में PostgreSQL डेटाबेस बनाएँ और database/schema.sql को Neon SQL Editor में एक बार चलाएँ।
3. Vercel Project Settings → Environment Variables में ये मान जोड़ें:
   - DATABASE_URL — Neon PostgreSQL connection string
   - ADMIN_USERNAME — व्यवस्थापक प्रवेश नाम
   - ADMIN_PASSWORD — लम्बा, अद्वितीय व्यवस्थापक गोपनीय शब्द
   - RAZORPAY_KEY_ID — Razorpay की सार्वजनिक key ID
   - RAZORPAY_KEY_SECRET — Razorpay की गोपनीय key
4. पहले Razorpay के test credentials से परीक्षण करें; उत्पादन में जाने से पहले अपने खाते और भुगतान प्रवाह की पुष्टि करें।
5. Deploy के बाद /api/health खोलें। डेटाबेस सही जुड़ा होने पर ok और database दोनों true होने चाहिए।

## मुख्य पृष्ठ
- / — सार्वजनिक वेबसाइट और पूजन निवेदन
- /admin.html — व्यवस्थापक पटल; केवल निर्धारित प्रवेश विवरण से उपयोग करें

## API
- GET /api/health — डेटाबेस स्थिति
- GET /api/pujans — सक्रिय पूजन सूची
- GET /api/products — सक्रिय सामग्री सूची
- POST /api/bookings — पूजन निवेदन
- POST /api/orders — सामग्री का अलग आदेश निवेदन
- GET /api/booking-status?id=...&phone=... — ग्राहक की स्थिति
- POST /api/create-payment — स्वीकृत निवेदन के लिए Razorpay order
- POST /api/verify-payment — सर्वर पर Razorpay signature सत्यापन
- GET/PATCH /api/admin — प्रवेश-सुरक्षित व्यवस्थापक कार्य

## महत्त्वपूर्ण
पूजन की तिथि स्वतः पक्की नहीं होती। व्यवस्थापक पहले यात्रा और समय की उपलब्धता की पुष्टि करता है, पूजन के अनुसार निश्चित शुल्क एवं अग्रिम निर्धारित करता है और फिर निवेदन स्वीकार करता है। एक ही तिथि/समय पर दो स्वीकृत पूजन रोकने के लिए डेटाबेस में unique index है। सामग्री के अलग आदेश के लिए भी व्यवस्थापक को पहले स्वीकृति देनी होगी।

पूरे भारत में सेवा यात्रा और तिथि की उपलब्धता के अधीन है। सामग्री के डाक/वितरण शुल्क को व्यवस्थापक द्वारा ग्राहक से पुष्टि करना आवश्यक है। वेबसाइट अभी स्वचालित WhatsApp/SMS सूचना, रिफंड प्रबंधन, Razorpay webhook reconciliation या पूर्ण सूची-प्रबंधन प्रदान नहीं करती; इन्हें उत्पादन विस्तार में जोड़ना चाहिए। भुगतान की सफलता का अंतिम प्रमाण Razorpay डैशबोर्ड और भुगतान रिकॉर्ड से भी मिलाएँ।
